# PALIMPSEST demo

Static GitHub Pages replay for the PALIMPSEST memory reconciliation project.

```bash
npm install
npm run dev
```

The browser demo uses sanitized, deterministic outputs from a verified HydraDB run. It intentionally contains no API keys and makes no live HydraDB requests.

The animated Tabs, Animated Badge, and Text Reveal primitives are adapted from [beUI](https://beui.dev/) (MIT). The Button, Card, Badge, and Separator primitives follow [shadcn/ui](https://ui.shadcn.com/) patterns.
